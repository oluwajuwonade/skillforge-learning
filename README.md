# SkillForge Learning

**Build Skills. Shape Your Future.**

SkillForge Learning is an independent, practical learning platform designed to help people develop relevant digital and analytical skills through structured learning, applied tasks, and demonstrable project work.

The central idea is simple: **learn a concept, apply it to a real task, and create evidence of capability.**

## What the platform currently showcases

The live build presents the following learning and progress features:

- **28-Day AI, Data & Income Challenge** — a structured challenge for building practical skills through focused activities.
- **Learning Paths** — guided routes through relevant learning areas.
- **Skill & Goal Assessment** — a way to connect learning activity with individual skill goals.
- **Project Lab** — an applied-work area intended to turn learning into practical outputs.
- **My Progress** — a view of learning progress, with locally stored progress and data export in the current build.

The exact functionality available can evolve as the platform is developed. Refer to the live application for the current experience.

## Learning areas

SkillForge Learning is organised around practical capability development in:

1. Data Analytics and Business Intelligence
2. Artificial Intelligence and Workflow Automation
3. Economics and Quantitative Research
4. Professional Analytics and Independent Work

These are the project's defined learning areas; this repository does not claim that every programme or module is already implemented in the live application.

## Learning philosophy

Skill development should produce more than course completion. A useful learning cycle should connect:

1. **Understand** — learn the underlying concept and methods.
2. **Apply** — use the knowledge to solve a realistic problem.
3. **Demonstrate** — produce a project, analysis, report, or other evidence of capability.
4. **Improve** — review the result and identify the next skill to develop.

## Current build and future development

The live application is an evolving project. Features such as learner accounts, cloud synchronisation, live AI coaching, payments, and certificates should be treated as future or planned capabilities unless and until they are visibly released in the application.
